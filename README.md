# EPUB Reader Plugin for Obsidian

EPUB Reader is a plugin for [Obsidian](https://obsidian.md) that brings seamless EPUB reading and note-taking directly into your vault. Enjoy reading your EPUB books styled with your current Obsidian theme, and capture knowledge as you go.

**Features:**

- 📖 **Read EPUB files** directly inside Obsidian, integrated with your current theme for a consistent reading experience.
- 🗂️ **Interactive Table of Contents:** Browse and jump to chapters, and easily copy links to any section for quick referencing in your notes.
- ⬅️➡️ **Arrow Keys:** Use Left/Right arrows to turn pages.
- ⬆️⬇️ **PageUp/PageDown:** Jump to next or previous chapter in the Table of Contents.
- ✂️ **Quote & Link:** Select text in your EPUB and copy a markdown-formatted quote with a link back to the exact location in the book.
- 🔗 **Smart Linking:** Paste links to EPUB locations or chapters anywhere in your vault for navigation.

## Getting Started with Development

This project includes a ready-to-use [devcontainer](https://containers.dev/) for development.

**To get started:**

1. Open the project in [Visual Studio Code](https://code.visualstudio.com/).
2. When prompted, reopen the workspace in the devcontainer.
3. The container comes with Node.js, npm, TypeScript, and ESLint pre-installed.
4. Run `npm install` if needed, then use `npm run dev` to start development.
